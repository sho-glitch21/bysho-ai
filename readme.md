# BYSHO — Interactive Portfolio

An interactive 3D portfolio and creative playground for BYSHO.

This project is built on top of the open-source Bruno Simon Folio 2025 foundation, released under the MIT license. The runtime, physics, rendering architecture and many production assets remain part of that upstream foundation; the experience is being rebranded and reimagined as BYSHO.

## Setup

Create `.env` from `.env.example`.

Install [Node.js](https://nodejs.org/en/download/) and run:

```bash
npm install --force
npm run dev
```

Production build:

```bash
npm run build
```

The production output is generated in `dist/`.

## Direction

BYSHO is being developed as an interactive world rather than a conventional résumé:

- creative technology
- AI and data
- visual experiments
- BYSHO originals and experiments
- future builds
